# Brain Tumor Detection (glioma vs normal MRI)

ResNet50 transfer-learning classifier with Grad-CAM heatmaps showing where the model is looking.
Trained on the PMRAM Bangladeshi Brain Cancer MRI dataset (Mendeley Data, doi:10.17632/m7w55sw88b.1, CC BY 4.0).

**Research demo, not a medical device.**

Source code: https://github.com/musawaghu/Brain-Tumor-Detection-DL
